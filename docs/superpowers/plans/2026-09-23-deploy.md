# LEO Debris: Deploy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the finished data API and web explorer live at **leo.kudayyurter.dev**. The API and scheduled data jobs run on AWS in us-east-2 (defined with CDK), the database is Neon, the website is on Vercel, and pushes to `main` deploy automatically.

**Architecture:**
- One Dockerfile in `api/` builds two images from shared layers:
  - `api`: uvicorn behind the AWS Lambda Web Adapter, streaming responses through a Function URL.
  - `jobs`: a plain Lambda handler that runs the ingest jobs and database migrations.
- Secrets live in SSM Parameter Store and are loaded into the environment at cold start. Globe snapshots move from local disk to S3.
- CDK (Python) defines three stacks:
  - `LeoRegistry`: the ECR repository.
  - `LeoCi`: the GitHub OIDC provider and deploy role.
  - `LeoApp`: the bucket, both functions, the schedules, logs, an alarm and the budget.
- GitHub Actions builds and pushes the images, runs `cdk deploy`, runs migrations and smoke-tests the API. Vercel builds `web/` from the same repo.

**Tech Stack:** Python 3.12, uv 0.12.17, boto3, moto 5 (tests), awslambdaric 4.0.4, AWS Lambda Web Adapter 1.1.0, aws-cdk-lib 2.270.0 + constructs 10, AWS CDK CLI 2.1143.0 (via `npx`), Docker (buildx), GitHub Actions, Vercel, Neon Postgres.

**Spec:** `docs/superpowers/specs/2026-09-22-leo-debris-design.md` (read §2, §3.6, §3.7, §4, §9). Code contracts: `api/app/config.py`, `api/app/jobs.py`, `api/app/ingest/snapshot.py`, `api/app/api/main.py`, `api/app/api/auth.py`, `web/src/lib/proxy.ts`.

**Order change (owner decision, 2026-09-23):** this deploy plan runs *before* the AI plan. So the AI parts of spec §9 are left out here and move to the AI plan: fastembed model files baked into the image, the `rag_ingest` job, and `/leo/LLM_MODEL`.

## Global Constraints

- AWS region **us-east-2**. The account comes from the CLI/OIDC credentials (`CDK_DEFAULT_ACCOUNT`), never hard-coded in code.
- Resource names: ECR repo `leo-api`; Lambdas `leo-api` and `leo-jobs`; SSM prefix `/leo/`; stacks `LeoRegistry`, `LeoCi`, `LeoApp`.
- SSM SecureString parameters: `/leo/DATABASE_URL`, `/leo/SPACETRACK_USER`, `/leo/SPACETRACK_PASS`, `/leo/ORIGIN_SECRET`. The owner creates them with the CLI. **No secret value may ever appear in the repo, a CDK template, a workflow file or a log line.**
- Lambda `leo-api`: container image, x86_64, 1,024 MB, 60 s timeout, Function URL with auth `NONE` and invoke mode `RESPONSE_STREAM`. Reserved concurrency comes from the CDK context `api_reserved_concurrency`: 10 by default, and 0 means "do not set".
- Lambda `leo-jobs`: container image, x86_64, 1,536 MB, 10 min timeout, no Function URL, no retries.
- Schedules (EventBridge Scheduler, UTC, no flexible window):
  - `ingest-satcat` daily at 05:17. This job already rebuilds the stats, which is the spec's "chained stats rebuild".
  - `ingest-gp` every 6 h at minute 41 (`41 0/6 * * ? *`), off the top of the hour as Space-Track asks.
- CloudWatch log retention 14 days. An AWS Budgets alert at $5/month. The alert email comes from the CDK context `alert_email`, which is passed on the command line or from a GitHub variable and is never committed.
- Images are built with `docker buildx build --platform linux/amd64 --provenance=false`. Lambda rejects images whose manifest carries attestations.
- Pinned versions: uv 0.12.17, Lambda Web Adapter 1.1.0, awslambdaric 4.0.4, aws-cdk-lib 2.270.0, CDK CLI `aws-cdk@2.1143.0`. CI uses Node 22 (jsii does not support Node 26; locally set `JSII_SILENCE_WARNING_UNTESTED_NODE_VERSION=1`).
- API code keeps working locally with no AWS at all. When `SNAPSHOT_BUCKET`/`SSM_PREFIX` are unset, behaviour is exactly as today (local snapshot dir, `.env`).
- Attribution text unchanged: `Data: USSPACECOM via Space-Track.org; CelesTrak.`
- Every commit message: subject, blank line, then the trailer `Co-Authored-By: <model> <noreply@anthropic.com>`, using two `-m` flags. Never push (the go-live checklist in Task 7 is the only place pushing happens, and the owner confirms it).
- `api/`: `uv run ruff check .` and `uv run pytest -q` pass before each commit. `infra/`: `uv run ruff check .` and `uv run pytest -q` pass before each commit.

## Review Focus

1. **A secret is missing from SSM at cold start.** Today `Settings()` would silently fall back to `postgresql://leo:leo@localhost` or run with no origin secret. In production, startup must fail loudly and name the missing parameter. *(Test: Task 1 `test_load_settings_requires_production_parameters`.)*
2. **ORIGIN_SECRET forgotten in production.** The Function URL would then be a public back door (§4). When `SSM_PREFIX` is set and there is no origin secret, the API refuses to start. *(Test: Task 1 `test_load_settings_requires_production_parameters` covers ORIGIN_SECRET explicitly.)*
3. **First deploy, before the first GP ingest:** the S3 snapshot object doesn't exist yet. `/api/globe/snapshot` must return the existing 404 JSON (the web shows "Orbit data not available yet"), not a 500 from a boto `NoSuchKey`. *(Test: Task 1 `test_snapshot_endpoint_404_when_s3_object_missing`.)*
4. **The scheduler, or a person, invokes `leo-jobs` with a missing or wrong `job`.** The function must fail fast with a clear message and touch no data. *(Test: Task 2 `test_handler_rejects_missing_or_unknown_job`.)*
5. **A new AWS account has a Lambda concurrency limit of 10.** A reserved concurrency of 10 then makes the whole deploy fail. `api_reserved_concurrency=0` must omit the property entirely. *(Test: Task 4 `test_reserved_concurrency_zero_omits_property`.)*

```python
"""AWS adapters, used only in production (SSM_PREFIX / SNAPSHOT_BUCKET set)."""
import os

import boto3
from botocore.exceptions import ClientError


def load_ssm_env(prefix: str, client=None) -> list[str]:
    """Copy every parameter under `prefix` into os.environ (decrypted), keyed by the last
    path segment. Variables that are already set win, so local overrides keep working."""
    client = client or boto3.client("ssm")
    set_names: list[str] = []
    pages = client.get_paginator("get_parameters_by_path").paginate(
        Path=prefix, WithDecryption=True, Recursive=False
    )
    for page in pages:
        for param in page["Parameters"]:
            name = param["Name"].rsplit("/", 1)[-1]
            if name not in os.environ:
                os.environ[name] = param["Value"]
                set_names.append(name)
    return set_names


class S3SnapshotStore:
    def __init__(self, bucket: str, client=None):
        self.bucket = bucket
        self.client = client or boto3.client("s3")

    def put(self, key: str, data: bytes) -> None:
        self.client.put_object(Bucket=self.bucket, Key=key, Body=data,
                               ContentType="application/octet-stream")

    def get(self, key: str) -> bytes | None:
        try:
            obj = self.client.get_object(Bucket=self.bucket, Key=key)
        except ClientError as exc:
            if exc.response["Error"]["Code"] in ("NoSuchKey", "404"):
                return None
            raise
        return obj["Body"].read()
```

```python
def load_settings() -> Settings:
```

```python
from pathlib import Path

from alembic import command
from alembic.config import Config
from alembic.runtime.migration import MigrationContext
from sqlalchemy import create_engine

API_ROOT = Path(__file__).resolve().parents[1]


def _sqlalchemy_url(url: str) -> str:
    return "postgresql+psycopg://" + url[len("postgresql://"):] if url.startswith(
        "postgresql://") else url


def upgrade_head(database_url: str) -> str:
    cfg = Config(str(API_ROOT / "alembic.ini"))
    cfg.set_main_option("sqlalchemy.url", database_url)
    command.upgrade(cfg, "head")
    engine = create_engine(_sqlalchemy_url(database_url))
    try:
        with engine.connect() as conn:
            return MigrationContext.configure(conn).get_current_revision()
    finally:
        engine.dispose()
```

- [ ] **Step 4: Implement `api/app/lambda_jobs.py`**

```python
"""Entry point of the `leo-jobs` Lambda (image target `jobs`).

EventBridge Scheduler invokes it with {"job": "ingest-satcat"} or {"job": "ingest-gp"}. The
deploy workflow invokes {"job": "migrate"}; the owner can run {"job": "all"} once to load data.
"""
import json
import logging

from app.config import load_settings
from app.jobs import JOBS, run_job
from app.migrate import upgrade_head

LAMBDA_JOBS = ("migrate", *JOBS)
log = logging.getLogger("leo.jobs")


def handler(event: dict | None, context) -> dict:
    job = (event or {}).get("job")
    if job not in LAMBDA_JOBS:
        raise ValueError(f"invalid job {job!r}; expected one of {', '.join(LAMBDA_JOBS)}")
    logging.getLogger().setLevel(logging.INFO)
    settings = load_settings()
    if job == "migrate":
        result = {"migrate": upgrade_head(settings.database_url)}
    else:
        result = run_job(job, settings)
    log.info("job %s finished: %s", job, json.dumps(result))
    return result
```

```python
from aws_cdk import aws_ecr as ecr
from aws_cdk import aws_iam as iam
from aws_cdk import aws_lambda as lambda_
from aws_cdk import aws_logs as logs
from aws_cdk import aws_s3 as s3
from constructs import Construct

SSM_PREFIX = "/leo/"
REPO_NAME = "leo-api"


class LeoAppStack(Stack):
    def __init__(self, scope: Construct, construct_id: str, *, image_tag: str,
                 alert_email: str, api_reserved_concurrency: int, **kwargs) -> None:
        super().__init__(scope, construct_id, **kwargs)
        self.alert_email = alert_email
        repo = ecr.Repository.from_repository_name(self, "Repo", REPO_NAME)

        self.bucket = s3.Bucket(
            self, "Snapshots",
            block_public_access=s3.BlockPublicAccess.BLOCK_ALL,
            encryption=s3.BucketEncryption.S3_MANAGED,
            enforce_ssl=True,
            removal_policy=RemovalPolicy.RETAIN,
        )
        ssm_read = iam.PolicyStatement(
            actions=["ssm:GetParametersByPath"],
            resources=[self.format_arn(service="ssm", resource="parameter",
                                       resource_name=SSM_PREFIX.strip("/"))],
        )
        common_env = {"SSM_PREFIX": SSM_PREFIX, "SNAPSHOT_BUCKET": self.bucket.bucket_name}

        self.api_fn = lambda_.DockerImageFunction(
            self, "ApiFunction",
            function_name="leo-api",
            code=lambda_.DockerImageCode.from_ecr(repo, tag_or_digest=f"api-{image_tag}"),
            architecture=lambda_.Architecture.X86_64,
            memory_size=1024,
            timeout=Duration.seconds(60),
            reserved_concurrent_executions=api_reserved_concurrency or None,
            environment=common_env,
            log_group=logs.LogGroup(self, "ApiLogs", log_group_name="/aws/lambda/leo-api",
                                    retention=logs.RetentionDays.TWO_WEEKS,
                                    removal_policy=RemovalPolicy.DESTROY),
        )
        self.bucket.grant_read(self.api_fn)
        self.api_fn.add_to_role_policy(ssm_read)
        url = self.api_fn.add_function_url(
            auth_type=lambda_.FunctionUrlAuthType.NONE,
            invoke_mode=lambda_.InvokeMode.RESPONSE_STREAM,
        )
        self.api_url = url.url

        self.jobs_fn = lambda_.DockerImageFunction(
            self, "JobsFunction",
            function_name="leo-jobs",
            code=lambda_.DockerImageCode.from_ecr(repo, tag_or_digest=f"jobs-{image_tag}",
                                                  cmd=["app.lambda_jobs.handler"]),
            architecture=lambda_.Architecture.X86_64,
            memory_size=1536,
            timeout=Duration.minutes(10),
            retry_attempts=0,
            environment=common_env,
            log_group=logs.LogGroup(self, "JobsLogs", log_group_name="/aws/lambda/leo-jobs",
                                    retention=logs.RetentionDays.TWO_WEEKS,
                                    removal_policy=RemovalPolicy.DESTROY),
        )
        self.bucket.grant_read_write(self.jobs_fn)
        self.jobs_fn.add_to_role_policy(ssm_read)

        CfnOutput(self, "ApiFunctionUrl", value=url.url)
        CfnOutput(self, "SnapshotBucketName", value=self.bucket.bucket_name)
```

```python
from aws_cdk import ArnFormat, CfnOutput, Stack
from aws_cdk import aws_iam as iam
from constructs import Construct

GITHUB_OIDC = "token.actions.githubusercontent.com"


class LeoCiStack(Stack):
    """Lets GitHub Actions on `main` deploy without stored AWS keys (spec §9)."""

    def __init__(self, scope: Construct, construct_id: str, *, github_repo: str,
                 **kwargs) -> None:
        super().__init__(scope, construct_id, **kwargs)
        provider = iam.OidcProviderNative(self, "GitHubOidc", url=f"https://{GITHUB_OIDC}",
                                          client_ids=["sts.amazonaws.com"])
        role = iam.Role(
            self, "DeployRole",
            role_name="leo-github-deploy",
            assumed_by=iam.WebIdentityPrincipal(provider.oidc_provider_arn, conditions={
                "StringEquals": {
                    f"{GITHUB_OIDC}:aud": "sts.amazonaws.com",
                    f"{GITHUB_OIDC}:sub": f"repo:{github_repo}:ref:refs/heads/main",
                }}),
        )
        role.add_to_policy(iam.PolicyStatement(
            actions=["sts:AssumeRole"],
            resources=[f"arn:aws:iam::{self.account}:role/cdk-hnb659fds-*-{self.account}-{self.region}"],
        ))
        role.add_to_policy(iam.PolicyStatement(actions=["ecr:GetAuthorizationToken"],
                                               resources=["*"]))
        role.add_to_policy(iam.PolicyStatement(
            actions=["ecr:BatchCheckLayerAvailability", "ecr:BatchGetImage",
                     "ecr:CompleteLayerUpload", "ecr:InitiateLayerUpload", "ecr:PutImage",
                     "ecr:UploadLayerPart"],
            resources=[self.format_arn(service="ecr", resource="repository",
                                       resource_name="leo-api")],
        ))
        role.add_to_policy(iam.PolicyStatement(
            actions=["lambda:InvokeFunction"],
            resources=[self.format_arn(service="lambda", resource="function",
                                       resource_name="leo-jobs",
                                       arn_format=ArnFormat.COLON_RESOURCE_NAME)],
        ))
        CfnOutput(self, "DeployRoleArn", value=role.role_arn)
```
